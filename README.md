# Vegane Stube

Vegane Stube is a community project for vegan recipes inspired by South Tyrol.

The website is available in German, Italian, and English. It is a static website designed for simple hosting, such as GitHub Pages.

## Contributing a recipe

1. Download the template from [`template/recipe.json`](template/recipe.json).
2. Fill it in and add a JPG photo with the same filename.
3. Set `rights_confirmed` to `true` only if you own or have permission to use the recipe text and photo.
4. Send both files to [vegane.stube@gmail.com](mailto:vegane.stube@gmail.com).
5. After editorial review, the recipe may be edited, translated, and published.

Detailed instructions are available in the [German contribution guide](de/mitmachen/), [Italian contribution guide](it/mitmachen/), and [English contribution guide](en/contribute/).
